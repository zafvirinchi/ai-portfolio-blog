## Question

What is Dependency Injection in Spring Boot?

## Answer

Dependency Injection is a design pattern where Spring creates and provides required objects instead of the class creating them manually.

## Example

```java
@Service
public class UserService {
    private final UserRepository userRepository;

    public UserService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }
}

## Question

What is a Component in Angular?

## Answer

A component is the basic building block of an Angular application.

It controls a part of the UI using:

- TypeScript class
- HTML template
- CSS styles
- Metadata decorator

## Example

```ts
@Component({
  selector: 'app-user',
  templateUrl: './user.component.html'
})
export class UserComponent {}
